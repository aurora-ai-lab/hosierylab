# Prompt guide

A full scene prompt and a hosiery prompt serve different purposes.

## Full scene prompt

Keeps the person, clothing, pose, camera, setting, light and hosiery together. Use it when reproducing a tested composition.

## Hosiery prompt

Keeps only reusable hosiery information: color, denier, transparency, knit, finish, motif, coverage, top edge, toe and heel. Add it after the clothing paragraph when building a new scene.

Recommended order:

```text
character and clothing → action and camera → hosiery paragraph → light and constraints
```

A useful hosiery paragraph names the garment type and at least three observable properties. For example:

```text
15D pure black pantyhose, ultra-sheer plain knit, natural low sheen,
visible fine fibers, reinforced toe and smooth waistband.
```

Keep adult and non-explicit wording, and avoid treating synthetic references as product photographs or official character material.
