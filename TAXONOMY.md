# Hosiery taxonomy

HosieryLab uses observable terms so that records can be compared across images and prompts.

## Core dimensions

| Dimension | Examples | Meaning |
|---|---|---|
| Denier | 5D, 8D, 15D, 20D, 40D, 80D, 100D | Approximate yarn weight and visual coverage |
| Coverage | ultra sheer, sheer, semi-opaque, opaque | How much skin shows through under the same light |
| Length | footie, ankle, crew, knee high, over-the-knee, thigh high, pantyhose | Where the garment ends |
| Garment type | pantyhose, tights, stockings, suspender stockings, fishnet | The construction and coverage pattern |
| Knit | plain, ribbed, mesh, open structure, seamed | Visible construction or surface structure |
| Finish | matte, natural, satin, gloss, wet-look, shimmer | Surface reflection and visual treatment |
| Motif | plain, polka dot, chevron, back seam, lace edge, hole pattern | Repeating or identifying visual detail |

## Naming pattern

Use the most specific stable description available:

`[motif] [denier] [color] [garment type]`

Examples: `15D pure black pantyhose`, `polka-dot 20D burgundy tights`, `40D matte charcoal thigh-high stockings`.

Do not replace specific garment details with a generic label when the construction matters.
