# 新手第一张图：怎么选你的第一条 prompt

第一次来，面对 2000 张卡片，不知道从哪条开始？按下面五步走，第一张图就不容易翻车。

## 第一步：先选一条简单的

如果你还没有特别想要的款式，本站建议从这里开始：

> **黑色 · 20–40D · 连裤袜 · 哑光或自然微光 · 素面（没有图案）**

[直接看这一组 →](/hosiery?color=black&denier=20-40&length=waist)

为什么建议从这里开始（这是本站的建议，不是测试结论）：

- **细节少，能出错的地方少。** 没有袜口、没有吊带、没有图案、没有后缝，模型需要画对的东西最少。
- **好判断。** 黑色和皮肤反差大，20–40D 透不透、两侧有没有加深，一眼就看得出来。（原理见 [黑丝为什么显瘦](/learn/black-sheer-slimming)）
- **好接进角色。** 连裤袜的腰头会被衣服盖住，对裙子长度要求最少。

如果你已经知道自己要什么，就直接用筛选。先定这三项就够了：**颜色、D 数、长度**。拿不准 D 数看 [Denier 是什么](/learn/denier)，拿不准长度看 [各种长度一图看懂](/learn/length-guide)。

## 第二步：看懂卡片

<!-- 配图 A（给设计）：一张卡片的截图，用引线标出：编号 HL-xxxx / 名称（D 数 + 颜色 + 类型 · 特点）/ 测试标签 / 复制丝袜 / 复制整图。 -->

每张卡片的名字都是同一个格式，比如：

> **HL-1641 · 20D Smoke Black Pantyhose · Glossy**

依次是编号、D 数、颜色、类型和一个特点（这里是光泽：亮面）。点进详情页，可以看到完整参数。

再看一眼**测试标签**：标着"已在 GPT 图像 · 9:16 测试"的，说明样图就是用这条 prompt 原文生成的。

## 第三步：先用「复制整图」原样跑一张

第一张图，**先别急着接进自己的角色**。

1. 点「复制整图」。
2. 原样粘贴进你的工具，一个字都不要改。
3. 生成一张，和样图对照。

这一步是为了确认：这条丝袜描述在你的工具里是管用的。如果原样都跑不出来，接进角色以后只会更难排查。

本站只在 GPT 图像、9:16 竖图上测试过。如果你用的是别的工具，效果我们不能保证，这一步就更重要。

## 第四步：对照检查五个地方

| 检查 | 对的样子 | 不对的样子 |
|---|---|---|
| ① 透明度 | 小腿正面透、两侧深，看得出 D 数的感觉 | 平涂一片黑，或者几乎看不到丝袜 |
| ② 两条腿 | 颜色、光泽完全一样 | 一条深一条浅，或者一条亮一条哑 |
| ③ 长度 | 袜口在该在的位置（连裤袜看不到袜口） | 连裤袜画出了大腿上的袜口 |
| ④ 脚 | 不穿鞋时，是穿着丝袜的脚 | 光脚，或者突然多了一双鞋 |
| ⑤ 质感 | 看得出是织物，有细细的织纹 | 像乳胶、皮革或者油漆 |

五项都对，这条就可以用了。有一两项不对，可以再生成一次；一直不对，就换一条卡片试试。

## 第五步：换成「复制丝袜」，接进你的角色

确认能跑出来以后，回到同一张卡片，点「复制丝袜」，把这一段接进你自己的角色 prompt。怎么接、要删掉什么，见 [复制丝袜 vs 复制整图](/learn/copy-hosiery-vs-full-prompt)。

之后想换效果，**一次只改一项**：先换 D 数，满意了再换光泽，再换长度。一次改好几项，出了问题不知道是哪一项造成的。想并排比较两条，用 [对比](/compare)。

## 新手常见的四个坑

1. **第一条就选最复杂的。** 渔网 + 后缝 + 蕾丝袜口 + 湿亮，出了问题很难判断是哪一项。先从简单的开始。
2. **只复制标题。** "20D 黑丝"四个字太少了，模型不知道你要多透、什么光泽。要复制按钮给的整段文字。
3. **两段丝袜描述叠在一起。** 你的角色 prompt 里原来写了丝袜，又粘了一段，模型会把两段混着画。粘之前先删掉旧的。
4. **把"穿着丝袜的脚"改成"光脚"。** 丝袜在脚上就不见了。

## 规则

只生成成年人物；不要用来生成真实存在的人，也不要用来复刻已有作品里的角色。详见 [使用条款](/terms)。
