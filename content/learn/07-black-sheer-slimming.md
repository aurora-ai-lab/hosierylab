# 黑丝为什么显瘦

## 一句话

薄透黑丝穿在腿上，**正面透、两侧深**，形成一道从中间到边缘的明暗渐变。这和化妆时在脸两侧打阴影、让脸看起来更立体是同一个道理。

先说清楚：腿不会真的变细。"显瘦"是眼睛读画面时的感受，效果会因光线、背景和角度不同而变化。

## 渐变从哪来

     一条在边缘斜着擦过表面，要穿过一长段丝袜、线圈在视线里叠在一起，标"深"。
     配图 B：同一条黑丝小腿的正面照示意，旁边一条从浅到深再到浅的灰度条，对应腿的左边缘 → 正中 → 右边缘。 -->

腿大致是个圆柱。看一条穿着薄透黑丝的腿，正面和两侧的情况不一样：

**正面：** 视线垂直穿过丝袜，只穿过一层，线圈之间的空隙正对着你，皮肤就从空隙里透出来。所以正面看起来是"黑 + 肤色"混出来的颜色，比较浅。

**两侧：** 视线斜着擦过腿的表面，要穿过更长一段丝袜。线圈在视线里一层层叠起来，空隙被挡住，皮肤透不出来。所以两侧更接近丝袜本身的黑。

**再加上拉伸：** 膝盖、小腿正面是丝袜被撑得最开的地方，线圈之间的空隙最大，所以比别处更透。弯腿的时候，膝盖会明显变浅。

这两件事加在一起，就是"正面浅、两侧深"。这是光学和几何上的原理，任何颜色的薄透丝袜都有，只是黑色和皮肤的反差最大，所以最明显。

## 为什么这样看起来更修长

画画、化妆、拍照都在用同一个规律：**中间亮、边缘暗，眼睛就会把它读成一个立体的圆柱。**

1. **边缘被"收"进去了。** 两侧的深色和背景、阴影更容易连在一起，眼睛会更多地注意中间那条浅色的带，腿的视觉宽度因此变窄。
2. **立体感更强。** 平涂一种颜色的腿看起来是"一片"，有渐变的腿看起来是"一根圆柱"，线条更清楚。
3. **颜色连续。** 深色把皮肤上的细小不均匀盖住了，从大腿到脚踝是一条连续的线。

背景也有关系：深色背景下，两侧的深色几乎和背景融在一起，收窄的效果更明显；本站样图用奶白色背景，腿的轮廓是清楚的，这时主要靠的是腿内部的渐变。这一点是经验判断。

## 哪个 D 数最明显

按上面的原理推断，同时也是常见的经验，不是测量结果：

| D 数 | 渐变 | 原因 |
|---|---|---|
| ≤10D | 很弱 | 太透了，两侧也透得出皮肤，整条腿主要是"肤色带一点灰" |
| **15–40D** | **最明显** | 正面还透得出皮肤，两侧已经接近纯黑，中间和边缘的差距最大 |
| 60D 以上 | 基本没有 | 正面也透不出皮肤了，整条腿接近均匀的黑，剩下的只有深色本身的效果 |

所以想要这种效果，**15–40D 是最值得先试的区间**。（D 数的分档见 [Denier 是什么](/learn/denier)）

## 别的颜色有没有？

有。藏青、深棕、烟灰、酒红这些深色薄透丝袜都有同样的渐变，只是和皮肤的反差没有黑色大，所以弱一些。肤色丝袜也有，但颜色太接近皮肤，几乎看不出来。

**光泽会加强它。** 亮面丝袜会在小腿正面多一道高光，"中间亮、两边暗"的结构就更明显。详见 [光泽怎么选](/learn/finish)。

## 写 prompt 时怎么保住这个效果

如果 prompt 里没写清楚，图像模型可能会把黑丝画成**一整片均匀的黑**，看起来就像打底裤，或者像刷了一层漆。渐变一没，上面说的效果也就没了。

所以本站每一条薄透和半透的 prompt 里，都会明确写一句：

> 小腿正面和膝盖处更透，沿腿部两侧颜色逐渐加深。

再加一句"不像油漆或乳胶"。这是本站写模板的做法，每个模型是否都照做，我们还在测试中。

如果你自己写 prompt，或者把黑丝换成别的 D 数，**记得保留这句描述**。只写"black sheer 20D"，模型画出的可能就是一片平涂的黑。
