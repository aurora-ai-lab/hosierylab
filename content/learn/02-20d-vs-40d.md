# 20D 和 40D 到底差在哪

## 一句话

**20D 是"看得见腿的丝袜"，40D 是"带一点透的颜色"。**

本站的分档里，20D 属于**薄透 sheer** 的最上沿，40D 属于**半不透 semi-opaque** 的最下沿，中间还隔着一档半透（25–35D）。数字只差一倍，在画面上却跨了两档。（分档见 [Denier 是什么](/learn/denier)）

## 并排看：四个地方不一样

| 看哪里 | 20D | 40D |
|---|---|---|
| ① 小腿正面 | 肤色清楚透出来，看得到皮肤本身的颜色 | 只隐约透一点肤色，大部分是丝袜本身的颜色 |
| ② 两侧边缘 | 正面浅、两侧深，渐变很明显 | 两侧也深，但正面本来就不浅，所以渐变比较弱 |
| ③ 膝盖、脚背 | 撑开的地方几乎接近光腿 | 撑开的地方才透出一点肤色，这是 40D 唯一明显"透"的位置 |
| ④ 颜色 | 黑色看起来偏灰，是黑和肤色混出来的颜色 | 黑色更实、更饱和，接近布料本身的黑 |

**远看全身的时候**（本站样图都是全身构图）：20D 读作"穿了丝袜的腿"，40D 读作"黑色的腿"。凑近看，40D 透肤的地方还看得出来；远看，基本只剩颜色。这是经验判断，还没有用本站样图逐张验证，不同光线下也会有出入。

## 黑色差得多，肤色差得少

上面说的主要是**黑色**。黑色和皮肤反差大，20D 和 40D 一眼就能分开。

**肤色**丝袜情况不一样：丝袜的颜色本来就接近皮肤，透不透不容易看出来。这时差别主要在"质感"上：20D 更像皮肤本身，40D 更像一层均匀的肤色，皮肤原来的细节被盖住了一些。这同样是经验判断，不是测量结果。

所以如果你在肤色丝袜里纠结 20D 还是 40D，最好直接看样图，或者放进 [对比](/compare) 里并排看。

**藏青、深灰、深棕这些深色**介于两者之间：和皮肤的反差没有黑色那么大，但比肤色大得多，所以 20D 和 40D 的区别仍然看得出来，只是没有黑色那么强烈。选深色的时候，可以直接按黑色的经验来判断，再把差别打个折扣。比如 [17D 藏青连裤袜](/hosiery/hl-1631) 和 [40D 藏青 tights](/hosiery/hl-1714)，可以放进对比里一起看。

## 在 prompt 里，两者是怎么写出差别的

只写数字，模型未必能把 20D 和 40D 画出区别。本站 prompt 用的是"D 数 + 透明度描述"：

- **20D（薄透）**：透过面料清楚看到肤色，小腿正面和膝盖处更透，沿腿部两侧逐渐加深。
- **40D（半不透）**：只有膝盖和小腿正面撑开的地方隐约透出肤色，其余部分颜色完整饱满。

如果你复制的是 [复制丝袜](/learn/copy-hosiery-vs-full-prompt) 那一段，这句描述已经在里面了。自己改 D 数的时候，记得把这句描述一起换掉，不要只改数字。

## 怎么选

问自己三个问题：

1. **想不想让人看到皮肤？** 想 → 20D；只要一点点 → 40D。
2. **画面里黑色要多"实"？** 要的是轻盈、透气 → 20D；要的是干净、完整的颜色块 → 40D。
3. **还拿不准？** 中间有 25–35D 的半透档，正好是两者之间的样子：[看 25–35D 黑丝 →](/hosiery?color=black&denier=25-35)

另外，光泽也会影响观感：同样是 20D，亮面看起来比哑光更"透亮"。这个在 [光泽怎么选](/learn/finish) 里单独讲。
