# 常见术语：welt、back seam、Cuban heel、mock seam……

按丝袜从上到下的位置排。每个词给出英文（行业用词）、中文，必要时加日文。

## 袜口

**welt（袜口）**
袜子最上面那一圈加厚的边，把袜子收住。本站在英文 prompt 里写成 "welt (top band)"，因为英文里 welt 也有"皮肤上的勒痕"的意思，加上 top band，模型就不会画成腿上的红印。

**lace top（蕾丝袜口）**
袜口是一圈蕾丝，大腿袜上最常见。

**silicone grip（硅胶防滑条）**
袜口内侧的一圈硅胶，让袜子不用吊带也能自己贴住大腿。有这种袜口的大腿袜叫 **stay-ups**，英国叫 **hold-ups**。[看硅胶防滑袜 →](/hosiery?type=stay_ups)

**comfort waistband（宽腰头）**
连裤袜上较宽、较平的腰头，穿上不容易勒出痕迹。

## 怎么挂住

**suspender / garter（吊带）**
从腰间的吊带腰封垂下来、扣住袜口的带子。英式英语叫 suspender，美式英语叫 garter，日文 ガーター。要注意，在英式英语里 garter 指的是套在腿上的一圈松紧带。挂吊带的袜子叫 **stockings**。[看吊带袜 →](/hosiery?type=stockings)

**suspender tights（假吊带连裤袜）**
一整条连裤袜，在大腿上部织出镂空，看起来像穿了吊带袜，其实没有吊带。[看假吊带 →](/hosiery?type=suspender_tights)

## 后缝

**back seam（后缝线）**
沿腿后面中线、从脚跟一直到袜口的一道细线。日文 バックシーム。最早来自 **fully fashioned（全成型）** 丝袜：先织成平片，再沿腿后缝合，所以真的有一道缝。

**mock seam（仿后缝）**
现在大部分丝袜是织成一个筒，本来没有缝。为了好看，在腿后面织或印一条线，看起来像后缝，这就是仿后缝。

本站卡片上会分别标"后缝"和"仿后缝"。在全身图里两者很难分开，**画面上重要的是线直不直**：后缝线歪了，比没有后缝更显眼。

示例：[HL-1206 10D 黑色及膝袜 · 后缝 + 古巴跟](/hosiery/hl-1206)

## 脚跟

**reinforced heel（加固跟）**
脚跟处织得更密，颜色比袜身深一点。最常见，主要是为了耐磨。

**Cuban heel（古巴跟）**
加固跟的一种：脚跟上一块**方形**的深色区域，上边是一条平直的线。常和后缝线一起出现。

**French heel（法式尖跟）**
也是加固跟，但形状是往上**收成一个尖**，比古巴跟更细长。

写 prompt 时要注意：Cuban heel 和 French heel 在英文里**也是鞋跟款式的名字**，模型可能会给你加一双鞋。本站的写法是 "Cuban-heel reinforcement knitted into the heel of the hosiery"，明确说是织在丝袜上的，并在不要的东西里写上"鞋"。

示例：[HL-1061 20D 法式尖跟 + 仿后缝](/hosiery/hl-1061)

## 脚尖

**reinforced toe（加固脚尖）**
脚尖处颜色深一点、织得更密。

**sheer toe / sandalfoot（透明脚尖）**
脚尖没有加固，和袜身一样透，适合露趾鞋。sandalfoot 直译就是"凉鞋脚"。

**seamless toe（无缝脚尖）**
脚尖没有横跨的缝线，或者缝线做得很平很细。

## 裤身（连裤袜）

**sheer to waist（全透到腰）**
从脚到腰都是同一个透明度，没有加厚的裤身。

**control top（收腹裤头）**
腰到臀部那一段织得更厚，颜色更深。穿短裙时，这段深色可能会露出来，选的时候留意一下。

## 织法和图案

**fishnet（渔网）**
菱形大孔的网，日文 網タイツ。透肤靠的是孔，所以没有 D 数，本站归到"镂空"档。[看镂空款 →](/hosiery?opacity=open_structure)

**jacquard（提花）**
图案是**织进去的**，不是印上去的。

**ribbed（罗纹）**
一条条竖向的凸纹，过膝长袜上常见。

## 风格词

**黒スト（黑丝）**
日文"黑色丝袜"的简称，指薄透到半透的黑色丝袜。为什么黑丝显腿细，见 [这篇](/learn/black-sheer-slimming)。

**絶対領域（绝对领域）**
裙摆和过膝袜袜口之间露出的那一段大腿。它是一种搭配，不是某一款袜子，要靠过膝袜加合适长度的裙子一起实现。[看过膝袜 →](/hosiery?length=over_the_knee)

**ルーズソックス（loose socks，泡泡袜）**
很长、很松、堆在小腿上的白色厚袜，来自 90 年代的日本街头。**本站目前没有这一类**，因为图库收的是贴腿的丝袜。

## 写 prompt 时，这几个词要换种说法

下面是本站写模板时专门处理过的歧义。处理后效果怎样，我们还在测试中。

| 原本想写 | 可能被误解成 | 本站的写法 |
|---|---|---|
| welt | 皮肤上的勒痕 | welt (top band) |
| Cuban heel / French heel | 鞋跟款式，画出一双鞋 | ...heel reinforcement knitted into the hosiery |
| no-show footies | 英文里意思是"藏在鞋里看不见"，可能被画成几乎没有袜子 | low-cut hosiery footies |
| 光脚 / barefoot | 丝袜在脚上消失 | 不穿鞋，穿着丝袜的双脚 / No shoes; stockinged feet |
