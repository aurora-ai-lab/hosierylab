# 光泽怎么选：glossy / satin / matte 上腿区别

## 先说结论

- **光泽看的是腿上的高光。** 腿是圆的，光打上去以后，小腿正面和膝盖会有一道亮带。光泽越强，这道亮带越亮、边缘越清楚。
- **哑光**看起来更像布料，颜色更"真"；**亮面**看起来更有立体感，腿的弧度更明显。
- 选光泽就是选"要不要强调腿的弧度"，跟 D 数是两回事，可以分开选。

## 本站的 7 种光泽

| 光泽 | 上腿看起来 | 高光长什么样 | 筛选 |
|---|---|---|---|
| **哑光** matte | 几乎没有光泽，像一层布 | 基本没有亮带 | [看哑光 →](/hosiery?finish=matte) |
| **自然微光** semi-matte | 有一点柔和的低光泽，最接近日常 | 很淡、很宽 | [看自然微光 →](/hosiery?finish=semi_matte) |
| **缎光** satin | 柔和、连续的光泽，有"丝"的感觉 | 沿小腿正面一条，边缘慢慢淡出 | [看缎光 →](/hosiery?finish=satin) |
| **亮面** glossy | 明显的光泽，看得出是亮面丝袜 | 顺着腿往下，边缘干净 | [看亮面 →](/hosiery?finish=glossy) |
| **高光** high-shine | 很亮，像镜面 | 一条又亮又清楚的连续亮带 | [看高光 →](/hosiery?finish=high_shine) |
| **湿亮** wet-look | 整条腿都在反光，像上了一层漆 | 亮带布满整条腿，但仍看得到织纹 | [看湿亮 →](/hosiery?finish=wet_look) |
| **闪光** shimmer | 纱里织进了细金属丝，有细碎的闪光 | 不是一条亮带，是沿着腿的弧度分布的小亮点 | [看闪光 →](/hosiery?finish=shimmer) |

"上腿看起来"和"高光长什么样"两栏，就是本站 prompt 里描述这几种光泽的方式。

## 光泽和 D 数怎么搭

下面是经验判断，不是测量结果，也还没有用本站样图逐张验证：

- **薄透（20D 以下）+ 亮面**：高光和透出的肤色混在一起，腿看起来"透亮"。同样是 20D，亮面看起来比哑光更透。
- **半不透、不透（40D 以上）+ 亮面**：皮肤基本看不到，高光就落在一整块颜色上，看起来更像一层有光泽的表面。湿亮和高光在这种厚度上最明显。
- **哑光 + 任何 D 数**：腿的弧度主要靠颜色的深浅来表现（正面浅、两侧深），光泽不抢戏。如果你想突出 D 数本身的透明度，哑光或自然微光最"诚实"。

光线也有影响。本站样图用的是柔和、均匀的棚拍光，所以亮带都比较柔。如果你的 prompt 里写的是硬光、点光源，同一种光泽会显得更亮、边缘更硬。

## 写 prompt 时最容易出错的地方

本站写模板时，针对下面几种情况专门加了限定。这些限定实际起多大作用，还在测试中。

| 光泽 | 容易被画成 | 本站的限定写法 |
|---|---|---|
| 湿亮 wet-look | 乳胶、皮革，或者像刷了油漆 | 写明"仍能看到织纹，不是乳胶" |
| 缎光 satin | 湿亮 | 写明"高光边缘柔和淡出，不是湿亮的反光" |
| 闪光 shimmer | 亮片 | 写明"细金属丝织在面料里，不是亮片" |
| 任何光泽 | 两条腿光泽不一样 | 写明"两条腿颜色、光泽完全一致" |

自己改 prompt 时，如果把光泽从哑光改成湿亮，**这些限定句要一起改**，不要只改一个词。

## 怎么选

- 想要日常、自然：**自然微光**或**哑光**。
- 想要有"丝"的质感，但不要太亮：**缎光**。
- 想让腿的弧度更明显、更立体：**亮面**或**高光**。
- 想要很强的造型感：**湿亮**，配 40D 以上效果最明显。
- 想要一点点闪：**闪光**，薄款上更细腻。

拿不准的时候，在 [对比](/compare) 里放两张同 D 数、不同光泽的卡片并排看。
