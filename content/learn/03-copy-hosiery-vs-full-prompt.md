# 复制丝袜 vs 复制整图，分别怎么用

每张卡片上都有两个按钮。它们复制的内容不一样，适合的人也不一样。

## 一张表看懂

| | 复制丝袜 · Hosiery | 复制整图 · Full prompt |
|---|---|---|
| 复制的是什么 | 只有**丝袜**那一段：颜色、D 数、透明度、光泽、织法、袜口、脚跟、脚尖 | 生成这张样图的**完整 prompt**：人物、服装、姿势、背景、光线，加上丝袜 |
| 适合谁 | **已经有自己角色**、只想换一双丝袜的人 | 想得到**和样图一样效果**的人，或者第一次来、想先试试的人 |
| 长度 | 一小段 | 很长，几千字符 |
| 测试情况 | 摘自已测试的整图 prompt，**还没有单独测试过** | 卡片上标"已在 GPT 图像 · 9:16 测试"的，就是用这条原文生成的 |

两个按钮复制的都是**纯文本**，可以直接粘贴进输入框，里面不带链接、参数或格式符号。不用登录。

## 什么时候用「复制整图」

- **第一次用本站**：先用整图，原样粘贴生成一次，看你的工具能不能出接近样图的效果。能出，说明这条丝袜描述在你的工具里是管用的。
- **你还没有角色**，想直接要一张好看的图。
- **你想学写法**：整图 prompt 里，丝袜、服装、姿势各写在哪一段、怎么写，都看得到。

拿到整图以后，可以改人物、服装、背景，**丝袜那一段尽量别动**。要换丝袜，就换一张卡片。

## 什么时候用「复制丝袜」

你已经有一段写好的角色 prompt，只想让角色穿上这双丝袜。这时复制整图反而麻烦，因为里面的人物和服装会跟你的角色打架。

### 接进你的角色，四步

```
[你的角色：外貌、发型、上半身服装……]
[粘贴：复制丝袜 的那一段]
[场景、构图、光线……]
```

1. **删掉原来关于腿的描述。** 原 prompt 里如果有"光腿"、别的袜子、长靴，先删掉。两段丝袜描述放在一起，模型会混着画。
2. **把丝袜段落放在服装描述后面。** 不需要改里面的文字。
3. **检查裙子长度。** 袜口要能被看到，丝袜的类型才画得出来。大腿袜配长裙，袜口被盖住，可能就被画成连裤袜。各长度对应多长的裙摆，见 [各种长度一图看懂](/learn/length-guide)。
4. **保留关于脚的那句话。** 丝袜段落里写的是"不穿鞋时是穿着丝袜的双脚"。不要改成"光脚"，那样丝袜在脚上就不见了。如果你的角色要穿鞋也可以，只是脚跟、脚尖的细节会被鞋挡住。

## 关于"已测试"标签

本站只在 **GPT 图像、9:16 竖图**上测试过。

- 标着"已在 GPT 图像 · 9:16 测试"：整图 prompt 原文就是用这个设置跑出样图的。
- 标着"未单独测试 · 摘自已测试的整图 prompt"：这是丝袜段落。它的文字和整图里那一段一样，但单独接进别的角色之后效果如何，我们还在测。

其他工具（Midjourney、Stable Diffusion 等）我们没有测过，所以卡片上不会写"支持"。你可以试，但效果我们不能保证。

## 使用规则

- 只生成成年人物。
- 不要用来生成真实存在的人。
- 不要用来复刻已有作品里的角色。
